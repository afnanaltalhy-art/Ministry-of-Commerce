# موقع جودة أعمال الخدمات المشتركة

## الرفع إلى GitHub
١. فكّي ضغط الحزمة.
٢. ارفعي جميع الملفات ومجلد assets إلى المستودع مباشرة، بحيث يظهر index.html في الصفحة الرئيسية للمستودع، وليس داخل مجلد إضافي. لا ترفعي ملف ZIP نفسه.
٣. من Settings ثم Pages اختاري Deploy from a branch ثم main و / (root) ثم Save.

## إدخال روابط الاستبيانات
افتحي surveys.js من GitHub ثم اختاري زر التعديل. الفرع madinah للمدينة المنورة وyanbu لينبع. عدّلي title لاسم الاستبيان، وأضيفي رابط المشاركة الكامل في url بين علامتي الاقتباس، ثم احفظي عبر Commit changes. لكل فرع ثلاثة استبيانات.

إذا تركتِ الرابط فارغًا يظهر «سيُتاح قريبًا». عند إضافته يتفعّل الزر تلقائيًا. استخدمي رابط المشاركة، لا رابط تعديل الاستبيان.

## الملفات
index.html: الصفحة الرئيسية
styles.css: التصميم
app.js: التبويبات والبطاقات
surveys.js: أسماء الاستبيانات وروابطها
assets/ministry-logo.png: شعار وزارة التجارة المرفق

الموقع يعرض روابط استبياناتك الخارجية؛ الردود تُجمع في منصة الاستبيان التي تستخدمينها.
